Tmux Cheat Sheet

Sessions

tmux new -s [name]new named session
tmux aattach to last session
tmux a -t [name]attach to session
tmux lslist sessions
Ctrl-b ddetach
Ctrl-b $rename session
Ctrl-b schoose session

Windows

Ctrl-b cnew window
Ctrl-b ,rename window
Ctrl-b wlist windows
Ctrl-b pprevious
Ctrl-b nnext
Ctrl-b 0\u20269jump to window
Ctrl-b &close window

Panes

Ctrl-b %split vertical
Ctrl-b "split horizontal
Ctrl-b onext pane
Ctrl-b xkill pane
Ctrl-b ztoggle zoom
Ctrl-b !pane \u2192 window
Ctrl-b \u2b05\u27a1\u2b06\u2b07navigate panes
Ctrl-b Ctrl-\u2b05\u27a1\u2b06\u2b07resize pane
Ctrl-b Spacecycle layouts

MQTT vs AMQP 0-9-1 Topic Syntax

MQTTAMQP 0.9.1Description
/ (slash). (dot)topic level separator
+ (plus)* (asterisk)single-level wildcard (match a single word)
# (hash)# (hash)multi-level wildcard (match zero or more words)
